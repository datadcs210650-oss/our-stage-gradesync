1. Chạy `supabase_migration.sql` trong Supabase SQL Editor.
2. Vercel Environment Variables:
   SUPABASE_URL=https://nkpfzjhqtdjcfypkishv.supabase.co
   SUPABASE_SECRET_KEY=<Secret key Supabase>
3. Upload toàn bộ thư mục này lên root GitHub/Vercel.
4. SuperAdmin phải có trong Auth + profiles.
5. BGK đăng nhập bằng Mã + Mật khẩu. Admin tạo BGK sẽ sinh mật khẩu tạm.
6. Giữ Firebase cũ làm backup trong thời gian test.
